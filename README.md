# دفتر الشدّة — Cards Scorebook

Score keeper for **Tarneeb 41** and **partnership Trex**, in Arabic, built for phones.

- `index.html` — the app (one self-contained, pure-ASCII file; this is what GitHub Pages serves)
- `shadda.html` — editable source
- `build.py` — regenerates `index.html` from `shadda.html`: `python build.py`

Scores are saved in each phone's browser. Use «انسخ البيانات» in the players tab to move them between devices.
